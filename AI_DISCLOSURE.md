# AI Disclosure — Machine Learning Midterm Project

**Project:** Breast Cancer Wisconsin and Wine Classification  
**Tool used:** OpenAI ChatGPT  
**Date of disclosure:** 11 November 2026

## Declaration

I used **ChatGPT (generative AI)** in the development of this project. My use included **generating and writing Python solution code with AI assistance** and **obtaining an AI-generated Word report outline/template**. I also used ChatGPT to help troubleshoot code, explain machine-learning concepts, organize numerical results, and correct or suggest wording in parts of the report.

This disclosure is intended to describe the assistance received, not to suggest that AI-generated work is equivalent to independently written work.

## Scope and limitations of AI assistance

- AI assistance was used for **implementation code**, not only for general explanations.
- The **report outline/template was AI-generated**.
- ChatGPT also provided **example report sentences and interpretation guidance**; the final submitted report should be reviewed to ensure this disclosure accurately reflects any wording retained.
- The numerical results in this project are associated with the notebook experiments and saved CSV outputs. They should be verified using the submitted notebooks and files; AI-generated explanations are not experimental evidence.
